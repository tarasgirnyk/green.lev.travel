# Green.Lev.Travel — наступні кроки

## План

1. [x] **Концепція** — [concept.md](concept.md)
2. [ ] **Фінмодель**
   - один будинок + кластер на 5 будинків;
   - три сценарії: песимістичний / базовий / оптимістичний;
   - порівняння «сам vs з Green»: дохід, час, ризики;
   - економіка самої Green: внески + частка прибутку → скільки об'єктів до беззбитковості, чи вистачає на трьох партнерів;
   - перевірка: пропорція 40/60, резервний фонд, знижки й винагороди клубу.
3. [ ] **2–3 реальні ділянки** з першою експертизою (ціна, фото, кадастр, під'їзд, комунікації).
4. [ ] **Лінійка будинків**: 2–3 типи з візуалізацією, площею, кошторисом (можна взяти напрацювання White: Compact / Comfort / VIP).
5. [ ] **Пітч** для стратегічного партнера і Божени: модель, ролі, конкретний запит.
6. [ ] **Письмові домовленості** партнерів: частки, ролі, вихід, ухвалення рішень.
