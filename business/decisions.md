# Green.Lev.Travel — журнал рішень

Хронологія обговорень бізнес-моделі (20–21.10.2026) і що з них вирішено. Повна модель — у [concept.md](concept.md).

---

## Як еволюціонувала ідея

1. **Початок.** Власна земля на Турківщині → презентація → інвестор будує будиночки → здача в оренду. Це White.Lev.Travel.
2. **Розширення.** Стати «вищою ланкою»: зводити землю й інвесторів, будувати брендовані типові будинки (до ~5 типів, від будиночка на двох до будинку на дві сім'ї), вести все під ключ. White.Lev.Travel — пілот цієї моделі.
3. **White.Lev.Travel на паузі** (сварка з партнером по землі). Рішення: реанімувати модель **без власної землі**.
4. **Уточнення моделі:** це не «чужа земля + чужі гроші». Інвестор **купує ділянку у власність**, яку підібрала й перевірила Green. Власник землі — звичайний продавець.
5. **Принцип продукту:** інвестору має бути помітно вигідніше з нами, ніж самому. Показуємо одразу дохід, вигоди і витрати часу.

## Вирішено

| Тема | Рішення |
|---|---|
| Формат | Кураторська + управляюча компанія. Не відкритий маркетплейс на старті, а відібрані перевірені проєкти |
| Земля | Інвестор купує ділянку у власність; земля й будинок повністю його |
| Вхідний внесок | 10% від вартості будівництва — комісія Green за організацію |
| Управління | Повне: власник нічим не займається. Green наймає й курує персонал на місці, продає бронювання |
| Не франшиза | Франшиза працює для розкачаного бренду; на старті пропонуємо більше — повне управління |
| Розподіл | Ділиться **чистий прибуток**, не оборот. Орієнтир 40/60 (Green / власник) |
| Витрати | З виручки віднімаються всі операційні витрати включно з ремонтами + маркетинг. Сайт, фото, бренд, робота Green — за рахунок частки Green |
| Збитки | Власник може вийти, якщо об'єкт збитковий. Механізм: гнучкий персонал + резервний фонд + перенесення збитку + річний розрахунок з авансами |
| Вихід | Власник може піти і керувати сам; правила виходу ще деталізувати |
| Експертиза | Обов'язкова до виставлення ділянки: юридична, технічна, ринкова, локація, відповідність моделі. На кожну — паспорт проєкту |
| Кабінет | Напівзакритий кабінет інвестора (запрошення / заявка зі схваленням), без власників землі. Фінмодель, бізнес-план, статус ділянки. Після купівлі — кабінет власника зі звітністю |
| Кластери | Шукати локації під 5–10 будинків поруч, щоб персонал був спільний |
| Команда | Тарас (концепція, бренд, IT), Божена (нотаріус, юр. частина, Львів), стратегічний партнер (Київ, зв'язки й перші клієнти, гроші не обов'язкові). Партнерів обираємо самі з тих, кому довіряємо |
| Клуб власників | Рекомендації — тільки від тих, хто вже збудував об'єкт; винагорода лише за реальну угоду; **один рівень**, умови відкриті для всіх |

## Відкинуто

- **Багаторівнева партнерська програма з внесками** і приховування умов від нових учасників. Причина: ознаки фінансової піраміди, юридичний і репутаційний ризик (особливо для нотаріуса й публічного партнера), руйнує довіру. Замінено на клуб власників з однорівневою винагородою.
- **Відкритий маркетплейс на старті.** Порожній майданчик виглядає мертвим; спершу кураторська вітрина 3–5 проєктів.
- **Комісія 10–12% з продажів за повне управління.** Не покриває операційку; перейшли на ділення чистого прибутку.

## Важливі застереження

- Фінмодель — **прогноз, не обіцянка** дохідності; формулювання погодити з Боженою.
- Статус стратегічного партнера (посадова/публічна особа): з юристом визначити допустиму форму участі.
- Бренд, домени й напрацювання оформити на себе до переговорів; частки й ролі — письмово.
- Немає жодного збудованого об'єкта: перший клієнт = пілот, вести максимально ретельно.
