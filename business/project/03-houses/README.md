# Будинки

Три типи будинків × чотири стилізації інтер’єру = 12 варіантів оформлення.

| Тип | Папка | Призначення |
|---|---|---|
| Comfort | [01-comfort](01-comfort/README.md) | Одноповерховий будинок для двох дорослих |
| Сімейний дворівневий | [02-family](02-family/README.md) | Студія з диваном унизу, спальня нагорі |
| Вілла | [03-villa](03-villa/README.md) | Дві спальні, вітальня, кухня та SPA-зона |

## Порядок роботи

1. Збираємо базову концепцію: планування, склад приміщень, комплектація та вигляд будинку.
2. Спільно затверджуємо її; дату й рішення записуємо в `concept/README.md` і журналі рішень.
3. Божена розробляє чотири стилізації інтер’єру під погоджені назви.
4. Погоджені візуали й описи готуємо для презентації.

Стилізація спирається на затверджену базу. Зміни планування або комплектації погоджуємо окремо. Назви тем Comfort взяті з поточного контексту; інші назви ще визначаємо. «Явір бойківський» — наявний напрям сімейного будинку, а не затверджений список чотирьох тем.
