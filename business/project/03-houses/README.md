- [Comfort — «Адам і Єва»](01-comfort/interiors/01/adam-eve.png) — погоджений дизайн.
- [«Солодкі сни» — варіант 01](02-family/interiors/01/sweet-dreams-design-v01.png) — блакитно-лавандовий, збережений для порівняння.
- [«Солодкі сни» — варіант 02](02-family/interiors/01/sweet-dreams-design-v02.png) — бежево-оливковий, без місяця; 10.11.2026 Божена надала йому перевагу. Остаточний вибір — після обговорення з Тарасом.

Обидва варіанти «Солодких снів» та дизайн «Верес Хіл» збережені в папках відповідних будинків; усі дизайни доступні з цього спільного списку. Попередні паспорти з кошторисами: [«Солодкі сни»](02-family/concept/passport.md) та [«Верес Хіл»](03-villa/concept/passport.md).

## Порядок роботи

1. Збираємо базову концепцію: планування, склад приміщень, комплектація та вигляд будинку.
2. Спільно затверджуємо її; дату й рішення записуємо в `concept/README.md` і журналі рішень.
3. Божена розробляє чотири стилізації інтер’єру під погоджені назви.
4. Погоджені візуали й описи готуємо для презентації.

Стилізація спирається на затверджену базу. Зміни планування або комплектації погоджуємо окремо. Назви тем Comfort взяті з поточного контексту; інші назви ще визначаємо. 10.11.2026 для поточної концепції сімейного будинку обрано назву «Студія снів» замість попереднього напряму «Явір бойківський»; список чотирьох тем ще не затверджений.

[До структури проєкту](../README.md)
