# Сімейний дворівневий — базова концепція

Унизу студія з диваном, кухня й санвузол; нагорі спальня. Є попередній напрям «Явір бойківський».

Статус у цій структурі: очікує спільного затвердження бази. Попередні напрацювання не вважаємо новим затвердженням.

Потрібно зібрати планування, площі, комплектацію, зовнішній вигляд і ключові обмеження для інтер’єрів. Площі та бюджет уточнюються.

Після погодження тут фіксуємо дату, учасників і посилання на остаточні матеріали.
