# Третій тип — робоча назва «4 друзі»

**[«Саме нове — ОК» — останній збережений комплект для обговорення](<concept/four-friends/Саме нове — ОК/README.md>)**: одноповерховий план із двома спальнями й 13 великих ракурсів, 17.11.2026.

17.11.2026 користувачка запропонувала спробувати назву **«4 друзі»** та три квадратні модульні схеми з двома закритими спальнями: одноповерхову, двоповерхову з обома спальнями нагорі й двоповерхову зі спальнею на кожному рівні. [Нові ескізи для порівняння](concept/four-friends/README.md). Остаточний варіант ще не обрано.

## Попередні матеріали — «Верес Хіл» / Veres Hill

[Остання одноповерхова пропозиція — дві спальні по боках холу, двері навпроти](concept/four-friends/single-storey-entry-redesign/README.md), 17.11.2026. На обговоренні. У збереженому комплекті «Саме нове — ОК» є [новий попередній кошторис](<concept/four-friends/Саме нове — ОК/four-friends-latest-layout-budget-2026-11-17.pdf>): 3,16-4,38 млн грн із меблями, зовнішніми опціями та резервом 15%, за припущенням 64 м²; без землі й зовнішніх комунікацій. Площі з візуалізації не вимірювали.

Нові матеріали від 17.11.2026: [паспорти трьох схем «4 друзі»](concept/four-friends/four-friends-preliminary-passports-2026-11-17.pdf) та [кошториси](concept/four-friends/four-friends-preliminary-budgets-2026-11-17.pdf), зібрані в [папці «4 друзі»](concept/four-friends/README.md). Наведені нижче попередні площі та цільовий бюджет «Верес Хіл» стосуються іншої геометрії.

Дворівневий будинок для двох пар або сімей: унизу кухня-вітальня студійного типу, нагорі дві окремі ізольовані спальні. За запитом користувачки від 10.11.2026 додаємо душ і туалет на другому поверсі. У першій пропозиції вони розділені на дві кімнати; унизу також пропонуємо санвузол із душем. 10.11.2026 користувачка обрала компактну основу орієнтовно 91 м² із бюджетною ціллю 80–90 тис. доларів і назву «Верес Хіл» / Veres Hill. Розміри ще перевіряємо на новому плані. Довідковий напрям — VIP із матеріалів White; назви чотирьох окремих стилізацій ще не визначені.
