# Green.Lev.Travel — план підготовки першого проєкту

*Створено 29.10.2026. Пов'язане: [concept.md](concept.md), [decisions.md](decisions.md), [next-steps.md](next-steps.md).*

## Мета

**Перший проєкт** — це готовий до показу інвестору пакет: перевірена ділянка (краще під кластер 5–10 будинків) + обраний тип будинку з інтер'єром + кошторис від підрядника + фінмодель + проєкти договорів. З цим пакетом іде пітч стратегічному партнеру і перший інвестор.

## Порядок робіт (критичний шлях)

```
1. Партнери і юр. основа ──────────────────────────────┐
2. Лінійка будинків → 3. Кошторис від підрядника ──┐   │
4. Пошук ділянок → експертиза ─────────────────────┼→ 5. Фінмодель → 6. Пакет інвестора → 7. Пітч
                                                    │   │
                     Договори (шаблони) ────────────┴───┘
```
Пункти 1, 2 і 4 та договори йдуть **паралельно**. Фінмодель можна збирати одразу на припущеннях і уточнювати, коли з'являються реальні цифри.

## Стратегічний партнер (після пітчу)

| # | Задача |
|---|---|
| П1 | Перші 1–3 інвестори з кола знайомств |
| П2 | Зв'язки: ділянки, підрядники, місцева влада |
| П3 | Відгук на модель і пакет інвестора до виходу на ширше коло |

## Спільно (рішення партнерів)

- Частки й ролі партнерів — письмово (Б3).
- Вибір винагороди за управління: 35–40% чистого або 20–25% виручки — після фінмоделі.
- Розмір X% для форс-мажору по матеріалах.
- Умови для перших власників, поки кластер не заповнений (знижка / Green покриває частину витрат).
- Перший об'єкт = пілот: чи давати знижку на комісію в обмін на право показувати об'єкт.

## Кого потрібно знайти

| Хто | Навіщо |
|---|---|
| Архітектор | Типові проєкти 3 типів |
| Підрядник (2–3 на вибір) | Кошторис, фіксована ціна, будівництво |
| Інженер / геодезист | Технічна експертиза ділянки: під'їзд, мережі, рельєф, зсуви |
| Бухгалтер | Податки, схема грошових потоків |
| Люди на місці | Прибирання, білизна, зустріч гостей — коли буде ділянка |

## Чек-лист «перший проєкт готовий до показу»

- [ ] Ділянка: паспорт з юр., технічною, ринковою експертизою і висновком по цільовому призначенню

- [ ] Фінмодель у трьох сценаріях з застереженням «прогноз»
- [ ] Проєкти договорів: бронювання, проєкт, управління
- [ ] Схема податків і грошових потоків
