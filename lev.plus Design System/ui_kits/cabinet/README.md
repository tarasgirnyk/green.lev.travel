# lev.plus — investor cabinet UI kit

Semi-closed cabinet (access by approved application). Night theme (Palette B) by default.

- `index.html` → `Cabinet.jsx`: sidebar, project list with status filter, project detail (ProjectCard horizontal + ділянка passport + 3-scenario finmodel).
- Interactions: filter chips, open project, «Забронювати ділянку» → status changes to reserved + notice.
- All figures are demo values; forecasts always labelled «прогноз».
